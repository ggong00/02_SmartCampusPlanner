# 🎓 Smart Campus Planner

**대학생을 위한, 학과·동아리·개인 할 일을 한곳에서 관리하는 웹 일정 관리 앱**

Smart Campus Planner는 별도의 회원가입이나 설치 없이, 웹 브라우저만 있으면 바로 사용할 수 있는 대학생 전용 할 일 관리 웹앱입니다. 달력과 할 일 목록을 한 화면에서 동시에 확인할 수 있고, 카테고리·중요도·기간을 함께 관리할 수 있어요.

---

## 📌 프로젝트를 만든 목적

대학생은 학과 과제, 동아리 활동, 개인 일정이 뒤섞여 있어서 관리해야 할 일이 매우 산발적입니다. 메모 앱, 캘린더, 메신저 등 여러 곳에 흩어진 할 일을 **하나의 도구로 통합**해서 관리할 수 있다면, 학업과 대외활동, 개인 생활의 균형을 잡는 데 도움이 될 것이라는 생각에서 이 프로젝트를 시작했습니다.

- 학과 / 동아리 / 개인의 모든 할 일을 한 화면에서 등록하고 관리
- 카테고리·중요도·마감일을 함께 관리해 우선순위를 쉽게 파악
- 완료율을 시각적으로 보여줘서 성취감과 실행 동기를 부여
- 새로고침하거나 브라우저를 다시 열어도 데이터가 사라지지 않는 실용적인 도구 제공

자세한 배경과 요구사항은 [`PRD.md`](./PRD.md) 문서에서 확인할 수 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 📝 할 일 추가 | 제목과 메모를 입력해서 새로운 할 일을 등록할 수 있어요 |
| ✏️ 인라인 수정 | 목록에서 수정 버튼을 눌러 바로 내용을 편집할 수 있어요 |
| 🏷️ 카테고리 설정 | 학과 / 동아리 / 개인 등으로 분류하고 색상으로 구분해서 볼 수 있어요 |
| ⭐ 중요도 설정 | 상 / 중 / 하 등 중요도를 정할 수 있어요 |
| ⚙️ 카테고리·중요도 커스터마이징 | 설정에서 카테고리와 중요도 항목을 자유롭게 추가하거나 삭제할 수 있어요 |
| 📅 시작일 ~ 마감일 지정 | 마감일뿐 아니라 "언제부터 언제까지"인지 기간으로도 지정할 수 있어요 |
| ⏰ D-day 표시 | 마감일까지 남은 날수를 D-day 형태로 표시하고, 임박·당일·초과를 색상으로 구분해요 |
| ✅ 완료 체크 | 체크박스를 눌러 완료 여부를 표시할 수 있고, 완료된 항목은 취소선으로 구분돼요 |
| 🗑️ 삭제 | 더 이상 필요 없는 할 일은 목록 또는 달력에서 삭제할 수 있어요 |
| 🔍 검색 | 제목 또는 메모 내용으로 할 일을 실시간 검색할 수 있어요 |
| 🔽 필터 & 정렬 | 카테고리·중요도·완료 여부로 필터링하고, 등록순·마감일순·중요도순으로 정렬할 수 있어요 |
| 📊 전체 완료율 표시 | 전체 및 카테고리별 완료 현황을 진행률 바로 실시간 보여줘요 |
| 🖥️ 달력 + 목록 동시 보기 | 데스크톱에서는 좌측 달력과 우측 목록을 한 화면에서 함께 볼 수 있어요 |
| 📋 ↔ 🗓️ 탭 전환 (모바일) | 태블릿·모바일에서는 버튼으로 목록과 달력을 전환해서 볼 수 있어요 |
| 🗓️ 달력 기간 시각화 | 달력 위에 시작일부터 마감일까지 막대(바) 형태로 표시되고, 카테고리별 색상과 완료 여부가 구분돼요 |
| 🔗 달력 ↔ 목록 연동 | 목록에서 항목을 클릭하면 달력이 해당 월로 이동하고 강조되고, 달력의 막대를 클릭하면 목록에서 해당 항목이 선택돼요 |
| 🌙 다크 모드 | 버튼 하나로 다크 모드를 전환할 수 있고, 설정이 브라우저에 저장돼요 |
| 💾 자동 저장 | 브라우저에 자동으로 저장되어, 새로고침하거나 다시 접속해도 내용이 그대로 남아있어요 |
| 📤 내보내기 / 📥 가져오기 | 할 일 데이터와 설정(카테고리·중요도)을 JSON 파일로 내보내고, 다른 기기에서 그대로 가져올 수 있어요 |

> 이 프로젝트가 어떤 순서로, 어떤 기준으로 단계별로 만들어졌는지는 [`TASKS.md`](./TASKS.md)와 [`PROMPTS.md`](./PROMPTS.md) 문서에서 확인할 수 있습니다.

## 🚀 사용 방법

별도의 설치나 로그인이 필요 없습니다. 아래 두 가지 방법 중 하나로 바로 사용할 수 있어요.

### 방법 1. 배포된 사이트에서 바로 사용하기
아래 GitHub Pages 링크에 접속하면 바로 사용할 수 있습니다.

> 🔗 **실행 링크**: [https://ggong00.github.io/02_SmartCampusPlanner/](https://ggong00.github.io/02_SmartCampusPlanner/)

### 방법 2. 내 컴퓨터에서 직접 열어보기
1. 이 저장소를 다운로드하거나 `git clone` 합니다.
2. 프로젝트 폴더 안의 `index.html` 파일을 더블클릭해서 웹 브라우저로 엽니다.
3. 바로 할 일을 추가하고 사용할 수 있습니다.

### 사용 순서
1. **+ 할 일 추가** 버튼을 눌러 폼을 열고 제목, 메모, 카테고리, 중요도, 시작일, 마감일을 입력합니다.
2. 추가된 항목은 우측 목록과 좌측 달력에 동시에 표시됩니다.
3. 목록에서 항목을 클릭하면 달력이 해당 월로 이동하며 강조됩니다.
4. 달력의 막대를 클릭하면 목록에서 해당 항목이 선택됩니다.
5. 체크박스로 완료 처리하거나, 수정(✏️) / 삭제 버튼으로 항목을 편집합니다.
6. 검색·필터·정렬로 원하는 항목만 추려볼 수 있습니다.
7. **⚙️ 설정**에서 카테고리와 중요도 항목을 추가하거나 삭제할 수 있습니다.
8. **내보내기**로 전체 데이터(할 일 + 설정)를 JSON 파일로 저장하고, **가져오기**로 다른 기기에서 동일하게 복원할 수 있습니다.
9. 브라우저를 새로고침하거나 다시 접속해도 입력한 내용은 그대로 남아있습니다.

## 🛠️ 사용한 기술

이 프로젝트는 별도의 서버나 프레임워크 없이, 웹 브라우저의 기본 기능만으로 만들어졌습니다.

- **HTML5** — 화면 구조 (입력 폼, 목록, 달력, 설정 모달 등)
- **CSS3** — 화면 디자인, CSS 변수 기반 다크 모드, CSS Grid 분할 레이아웃, 반응형(모바일·태블릿·데스크톱) 스타일
- **JavaScript (Vanilla JS, ES6+)** — 할 일 추가/수정/완료/삭제, 완료율 계산, 필터·정렬·검색, 달력 렌더링, D-day 계산, 설정 관리 등 모든 동작 로직
- **Web Storage API (`localStorage`)** — 할 일, 설정(카테고리·중요도), 다크 모드 상태를 브라우저에 저장
- **GitHub Pages** — 별도 서버 구축 없이 정적 웹사이트를 무료로 배포

> 별도의 설치 프로그램(Node.js, 빌드 도구 등) 없이, 브라우저만 있으면 실행할 수 있도록 순수 HTML/CSS/JS로 구현했습니다.

## 📁 프로젝트 파일 구성

```
02_SmartCampusPlanner/
├── index.html    # 화면 구조 (입력 폼, 달력+목록 분할 레이아웃, 설정 모달)
├── styles.css    # 전체 디자인 (CSS 변수, 다크 모드, 반응형 스타일)
├── script.js     # 동작 로직 (추가/수정/완료/삭제/필터/정렬/검색/달력/설정/내보내기/가져오기)
├── PRD.md        # 프로젝트 요구사항 정의 문서 (목적, 대상 사용자, 기능, MVP 범위)
├── TASKS.md      # 단계별(1~5단계) 구현 작업 계획 문서
├── PROMPTS.md    # 각 단계를 구현할 때 사용한 요청 프롬프트 모음
└── README.md     # 지금 보고 있는 프로젝트 소개 문서
```

| 문서 | 역할 |
|---|---|
| `PRD.md` | 이 앱을 왜 만드는지, 누구를 위한 것인지, 어떤 기능이 필요한지 정리한 문서 |
| `TASKS.md` | 전체 기능을 단계별로 나누어, 각 단계에서 무엇을 만드는지 설명한 문서 |
| `PROMPTS.md` | 각 단계를 실제로 구현할 때 사용한 요청 문구와 확인 체크리스트 모음 |
