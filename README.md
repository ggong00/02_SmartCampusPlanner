# 🎓 Smart Campus Planner

**대학생을 위한, 학과·동아리·개인 할 일을 한곳에서 관리하는 웹 일정 관리 앱**

Smart Campus Planner는 별도의 회원가입이나 설치 없이, 웹 브라우저만 있으면 바로 사용할 수 있는 대학생 전용 할 일 관리 웹앱입니다. 할 일을 목록으로 확인할 수도 있고, 달력 위에서 기간을 한눈에 볼 수도 있습니다.

---

## 📌 프로젝트를 만든 목적

대학생은 학과 과제, 동아리 활동, 개인 일정이 뒤섞여 있어서 관리해야 할 일이 매우 산발적입니다. 메모 앱, 캘린더, 메신저 등 여러 곳에 흩어진 할 일을 **하나의 도구로 통합**해서 관리할 수 있다면, 학업과 대외활동, 개인 생활의 균형을 잡는 데 도움이 될 것이라는 생각에서 이 프로젝트를 시작했습니다.

- 학과 / 동아리 / 개인의 모든 할 일을 한 화면에서 등록하고 관리
- 카테고리·중요도·마감일을 함께 관리해 우선순위를 쉽게 파악
- 완료율을 시각적으로 보여줘서 성취감과 실행 동기를 부여
- 새로고침하거나 브라우저를 다시 열어도 데이터가 사라지지 않는 실용적인 도구 제공

자세한 배경과 요구사항은 [`PRD.md`](./PRD.md) 문서에서 확인할 수 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 📝 할 일 추가 | 제목을 입력해서 새로운 할 일을 등록할 수 있어요 |
| 🏷️ 카테고리 설정 | 학과 / 동아리 / 개인 중 하나로 분류하고, 색상으로 구분해서 볼 수 있어요 |
| ⭐ 중요도 설정 | 상 / 중 / 하 중요도를 정할 수 있어요 |
| 📅 시작일 ~ 마감일 지정 | 마감일뿐 아니라 "언제부터 언제까지"인지 기간으로도 지정할 수 있어요 |
| ✅ 완료 체크 | 체크박스를 눌러 완료 여부를 표시할 수 있고, 완료된 항목은 취소선으로 구분돼요 |
| 🗑️ 삭제 | 더 이상 필요 없는 할 일은 삭제할 수 있어요 |
| 📊 전체 완료율 표시 | 전체 할 일 중 몇 %를 완료했는지 실시간으로 보여줘요 |
| 📋 ↔ 🗓️ 목록·달력 보기 전환 | 버튼 하나로 목록 화면과 달력 화면을 자유롭게 오갈 수 있어요 |
| 🗓️ 달력 기간 시각화 | 달력 위에 할 일이 시작일부터 마감일까지 막대(바) 형태로 표시되고, 카테고리별 색상과 완료 여부가 함께 구분돼요 |
| 💾 자동 저장 | 브라우저에 자동으로 저장되어, 새로고침하거나 다시 접속해도 내용이 그대로 남아있어요 |

> 이 프로젝트가 어떤 순서로, 어떤 기준으로 단계별로 만들어졌는지는 [`TASKS.md`](./TASKS.md)와 [`PROMPTS.md`](./PROMPTS.md) 문서에서 확인할 수 있습니다.

## 🚀 사용 방법

별도의 설치나 로그인이 필요 없습니다. 아래 두 가지 방법 중 하나로 바로 사용할 수 있어요.

### 방법 1. 배포된 사이트에서 바로 사용하기
아래 GitHub Pages 링크에 접속하면 바로 사용할 수 있습니다.

> 🔗 **실행 링크**: [https://ggong00.github.io/02_SmartCampusPlanner/](https://ggong00.github.io/02_SmartCampusPlanner/)
>
> _(GitHub Pages 배포 후 실제 주소로 교체해주세요.)_

### 방법 2. 내 컴퓨터에서 직접 열어보기
1. 이 저장소를 다운로드하거나 `git clone` 합니다.
2. 프로젝트 폴더 안의 `index.html` 파일을 더블클릭해서 웹 브라우저로 엽니다.
3. 바로 할 일을 추가하고 사용할 수 있습니다.

### 사용 순서
1. 화면 위쪽 입력창에 할 일 제목을 적습니다.
2. 카테고리(학과/동아리/개인), 중요도(상/중/하), 시작일(선택), 마감일을 선택합니다.
3. **"+ 할 일 추가"** 버튼을 누르면 목록에 새 할 일이 나타납니다.
4. **"📋 목록 보기" / "🗓️ 달력 보기"** 버튼으로 원하는 화면으로 전환합니다.
5. 체크박스를 눌러 완료 처리하거나, 삭제 버튼(또는 달력의 × 버튼)으로 할 일을 지울 수 있습니다.
6. 화면 위쪽 "전체 완료율"에서 진행 상황을 확인할 수 있습니다.
7. 브라우저를 새로고침하거나 다시 접속해도 입력한 내용은 그대로 남아있습니다.

## 🛠️ 사용한 기술

이 프로젝트는 별도의 서버나 프레임워크 없이, 웹 브라우저의 기본 기능만으로 만들어졌습니다.

- **HTML5** — 화면 구조 (입력 폼, 목록, 달력 등)
- **CSS3** — 화면 디자인, 색상 구분, 반응형(모바일 대응) 레이아웃
- **JavaScript (Vanilla JS, ES6+)** — 할 일 추가/완료/삭제, 완료율 계산, 목록·달력 렌더링 등 모든 동작 로직
- **Web Storage API (`localStorage`)** — 브라우저에 할 일 데이터를 저장해서 새로고침 후에도 유지
- **GitHub Pages** — 별도 서버 구축 없이 정적 웹사이트를 무료로 배포

> 별도의 설치 프로그램(Node.js, 빌드 도구 등) 없이, 브라우저만 있으면 실행할 수 있도록 순수 HTML/CSS/JS로 구현했습니다.

## 📁 프로젝트 파일 구성

```
02_SmartCampusPlanner/
├── index.html    # 화면 구조 (입력 폼, 목록 화면, 달력 화면)
├── styles.css    # 전체 디자인 (색상, 레이아웃, 반응형 스타일)
├── script.js     # 동작 로직 (추가/완료/삭제/완료율/저장/달력 렌더링)
├── PRD.md        # 프로젝트 요구사항 정의 문서 (목적, 대상 사용자, 기능, MVP 범위)
├── TASKS.md      # 단계별(1~5단계) 구현 작업 계획 문서
├── PROMPTS.md    # 각 단계를 구현할 때 사용한 요청 프롬프트 모음
└── README.md     # 지금 보고 있는 프로젝트 소개 문서
```

| 문서 | 역할 |
|---|---|
| `PRD.md` | 이 앱을 왜 만드는지, 누구를 위한 것인지, 어떤 기능이 필요한지 정리한 문서 |
| `TASKS.md` | 전체 기능을 1~5단계로 나누어, 각 단계에서 무엇을 만드는지 설명한 문서 |
| `PROMPTS.md` | 각 단계를 실제로 구현할 때 사용한 요청 문구와 확인 체크리스트 모음 |
